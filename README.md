## 🚀 Featured Projects

### [SMS Management Platform](https://github.com/junior-gerome/smsprojects)

A full-stack SMS management application with an Angular frontend and a Spring Boot backend. The project explores user and role management, contacts, campaigns, templates and SMS provider integration.

**Technologies:** Angular, TypeScript, Tailwind CSS, Java, Spring Boot, Spring Security, JWT, Gradle and relational databases.

### [Video Player & Streaming](https://github.com/junior-gerome/video-player-streaming)

A web application for managing video uploads, playlists and playback, with HTTP range-based streaming and object storage integration.

**Technologies:** Angular, Tailwind CSS, Java, Spring Boot, MySQL, MinIO and Docker.

### [Employee Management Application](https://github.com/junior-gerome/AppSal_Nguep_manyo)

An application focused on managing employees and salary-related information.

### [Classical Encryption Application](https://github.com/junior-gerome/Chiffrement)

A learning project exploring Caesar, Vigenère and Hill classical encryption algorithms.
